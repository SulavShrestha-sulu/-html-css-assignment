About This Website

This website is built with only HTML5 and CSS3. The goal is to practise semantic HTML, the CSS box model, Flexbox for the navigation bar, CSS Grid for the course cards, hover effects, and responsive design.

  • Semantic tags: header, nav, main, section, article, footer
  • Navigation layout with Flexbox
  • Course card layout with CSS Grid
